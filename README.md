# Project 2: Decentralized Identity and Access Management (IAM) dApp

A real-world problem we want to solve is users relying on and trusting centralized authorities, and the problem here is that organizations store critical personal information in centralized databases, meaning if this system gets breached, then user information will get leaked and will hurt the organization with the loss of trust between user and organization. For our real-world problem, we chose the incident that occurred during finals week where ASU, alongside many universities, relied on centralized applications and was breached by hackers, ShinyHunters.




# Dependencies:
Ethereum: Stores shared DID, issuer, and credential-status records
Solidity: Creates smart contracts to register identities and manage credentials
HardHat: Runs and tests smart contracts locally and measures gas usage
SHA-256: Generates credential hashes for integrity checking
